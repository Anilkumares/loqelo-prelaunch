# Loqelo – pre-launch website (design demo)

Pre-launch landing page for Loqelo, launching February 2027. Tagline: "Everything your place needs."

This is a **demo build**: the waitlist forms are simulated (`previewMode: true` in `config.js`), so nothing is saved.
The production version sends sign-ups to Brevo through a small PHP endpoint, and analytics are handled by consent-based Google Analytics 4.

## Two design versions

- Version 1: https://anilkumares.github.io/loqelo-prelaunch/
- Version 2: https://anilkumares.github.io/loqelo-prelaunch/v2/

Both share the same form, translations, analytics and assets.
